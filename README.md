# Feiyang 的 desktop.ini 编辑器 | Feiyang's desktop.ini editor
## 功能
> 为你的文件夹添加desktop.ini，自定义文件夹的显示！

### 自定义文件夹**显示**名

你的文件夹路径又臭又长？我来解决！

> 此功能可以在不改变文件夹原名称的前提下修改显示的名称
> cmd等获取路径的时候会使用原名称

### 自定义文件夹图标

顾名思义，很有趣（不过Windows的属性也可以改）

> 此功能可以改变文件夹显示图标
> 也可以使用Windows自带的属性修改，在本编辑器中可以看到原始形式

### 自定义文件夹悬停提示

给你的鼠标悬停提示加上一层独特的标签！

> 此功能会在文件夹本身悬停提示最上方额外加上一条自定义的悬停提示

### 自定义文件名

非常方便的功能

> 此功能可以在文件夹内的文件原始名不改变的前提下修改显示名称（后缀改不掉哦）

### 更多高级选项

1. desktop.ini不再隐形！可修改是否设置为系统文件和隐藏文件
2. 两种编码，兼容良好！自定义文件名如果需要中文就用UTF-16 LE如果不需要可以试试ANSI（但是不推荐）

其他功能，敬请期待！
